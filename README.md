> Ultra-Luxury Automotive Rental & Bespoke Mobility Platform for Saudi Arabia, the GCC, and International Clientele.

## 🌟 Overview

**CAR 2 GO** is a production-grade luxury automotive mobility platform featuring:
- **Light UI Baseline & Soft Lemon Accents**: Warm off-white surfaces (`#FFFFFF`, `#FAFAFA`) contrasted with deep charcoal typography (`#09090B`) and brand **Soft Lemon** (`#E2F163`) accents.
- **3D WebGL Cinematic Hero & Story Engine**: 8-scene automated cinematic director camera sweeping through reflective studio floors, softbox arrays, and dynamic rim lighting.
- **Bilingual & Native RTL Architecture**: Seamless switching between English (LTR) and Arabic (RTL) powered by **Manrope** & **Tajawal** typography.
- **4-Step Digital Concierge Booking Engine**: Location & schedule selector, live date-conflict prevention, tailored VIP add-ons (Runway Hand-Off, Chauffeur, Zero-Deductible Protection, Child Seat, GCC Cross-Border Permit), and instant digital boarding pass generation.
- **Customer Portal & Admin Management Suite**: Real-time booking pipeline, fleet CRUD, KPIs, inquiries, promo manager, and business settings.

## 🚀 Quick Start

### 1. Backend Server
```bash
cd backend
npm install
node server.js
```
*Backend runs on `http://localhost:5001` with auto-seeded luxury fleet data and embedded persistent storage.*

### 2. Frontend Application
```bash
cd frontend
npm install
npm run dev
```
*Frontend runs on `http://localhost:3000` with Vite proxy forwarding `/api` requests to port `5001`.*
